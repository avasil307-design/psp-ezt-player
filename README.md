# EZT Player — Material You homebrew для PSP

Прототип интерфейса видеоплеера для PSP, экран 480×272, portable C99 renderer, семь палитр Material 3 и светлый/тёмный режим. Шесть встроенных иллюстраций — **демо-контент**, не реальные видео.

## Предпросмотр на ПК

Нужен host GCC:

```sh
make preview
```

PNG-кадры появятся в `build/preview-library.png`, `build/preview-settings.png` и `build/preview-player.png`. Для одной палитры:

```sh
./build/preview /tmp/library.png 6 0  # динамическая палитра, тёмный режим
./build/preview /tmp/library-light.png 2 1
```

Индексы палитр: 0 Лаванда, 1 Океан, 2 Бирюза, 3 Хвоя, 4 Закат, 5 Роза, 6 Динамическая. Последняя извлекает seed-цвет из обложки выбранного демо-видео. Схема формируется из seed в OKLCH с gamut mapping; смена палитры и режима анимирована.

## Сборка для PSP

Установите PSPDEV/PSPSDK и его переменные окружения, затем в корне репозитория:

```sh
make psp
```

Ожидается `EBOOT.PBP`. Навигация: D-pad — перемещение, ✕ — выбрать/пауза, ○ — назад, L/R — переключение вкладки/видео, △ — настройки, □ — смена палитры.

## Текущее состояние MVP

Уже есть библиотека демо-видео, карусель, экран настроек с семью темами, переходы, тёмный/светлый режим, программный framebuffer и PSP UI entry point. Добавлен переносимый ISO-BMFF демультиплексор для обычных (не fragmented) MP4 с AVC `avc1`/`avc3`: читает таблицы образцов и SPS/PPS, извлекает AVC access units в Annex B; проверяется `make test`. Он пока не подключён к PSP экрану плеера. **Аппаратное декодирование на PSP, вывод кадров и AAC-аудио ещё не реализованы**, поэтому текущий EBOOT не воспроизводит MP4; экран плеера по-прежнему демонстрационный. PSP MP4-путь требует отдельной интеграции ME/AVC и AAC сервисов и проверки на PSP/PPSSPP. `sceMpeg` сам по себе не является универсальным MP4-декодером.

## Пересборка ресурсов

Генераторы работают повторно без ручной правки:

```sh
python tools/fetch_fonts.py && python tools/bake_fonts.py && python tools/gen_art.py
```

`fetch_fonts.py` берёт шрифты из npm; для Python-зависимостей см. `tools/requirements.txt`.
